Questions people ask

Is the download really free?

Yes. The export is a browser print to PDF, so there is nothing for us to charge for and no watermark to remove.

Do I need an account?

No. There is no sign-up because there is no server storing anything. Use the Save file button to keep a copy on your own machine.

Will it pass an applicant tracking system?

Single-column layouts such as Linden and Plainfield parse most reliably. Sidebar layouts look better but can confuse parsers that read across columns.

Can I edit it again later?

Save file downloads your current state as an HTML file. Open that file again and carry on where you stopped.

Can I get it as a Word document?

Yes, though Word receives a simplified table version. Diagonals and round photos are beyond what Word can draw.
